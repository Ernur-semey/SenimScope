# SenimScope brand

## Direction

Quiet, clear, warm, and collaborative. The interface should feel like a careful workroom for agreements rather than a finance dashboard. Use short, neutral language. Treat AI as a helper that surfaces evidence; leave decisions to the people doing the work.

## Palette: Ivory Linen

| Token | Light value | Use |
|---|---|---|
| Background | `#FAF8F5` | Main canvas |
| Surface | `#FFFFFF` | Cards, inputs, dialogs |
| Primary | `#953E32` | Main actions and selected states |
| Soft accent | `#D37D6F` | Suggestions and warm highlights |
| Foreground | `#1A1413` | Main text |
| Muted foreground | `#706660` | Supporting text |
| Border | `#E7DFD8` | Card and field boundaries |
| Success | `#426348` | Accepted/complete states |
| Danger | `#A72F2F` | Errors and destructive actions |

Keep surfaces light and warm. Use the rust accent sparingly for user actions; use green only for confirmed progress. No gradients in the product UI.

## Typography

- **Inter** for interface text, headings, and body copy.
- **JetBrains Mono** for short technical labels, versions, and on-chain identifiers.
- Use sentence case. Reserve uppercase for compact metadata labels.

## Voice

- Say what changed and why, with evidence.
- Prefer “Возможно, это новый объём” over categorical AI verdicts.
- Make consent explicit: “Создать запрос”, “Принять этап”.
- Do not imply a transaction or approval happened before confirmation.

## Accessibility

Use semantic buttons and headings, visible keyboard focus, labels for icon-only controls, and text alongside color-coded states. Keep body text at readable sizes; never rely on color alone to communicate approval or risk.

Palette and interface typography previews are retained in `.brand-preview/` for reference.
